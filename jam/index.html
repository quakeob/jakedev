JAM

Press and hold the mark.

An agent development environment for hackathon teams. Hold a key and talk. Seconds later, every coding agent on the team can search what you said.

Cam Hess and Jake Davis built JAM in one day at the Cloud Native Hackathon in Salt Lake City. From 1 PM the team talked into it, and the agents building it read from it.

Shared context

Every coding agent on the team connects to one MCP server and reads the same brain. Before an agent edits a file it claims the path, and the claim is refused if someone else holds it.
